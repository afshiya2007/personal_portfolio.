AFSHIYA BANU - PERSONAL PORTFOLIO WEBSITE

1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open Terminal > New Terminal.
4. (Recommended) Create and activate a virtual environment:

   py -m venv venv
   .\venv\Scripts\Activate.ps1

   If PowerShell blocks activation, run:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

   Then activate again:
   .\venv\Scripts\Activate.ps1

5. Install requirements:

   py -m pip install -r requirements.txt

6. Start the website:

   py app.py

7. Open this address in your browser:
   http://127.0.0.1:5000

NOTES
- The contact form saves messages to portfolio.db in this folder.
- It does not send emails.
- Update the skills and project descriptions so they accurately reflect your own work.
- Add your GitHub profile URL when you have one.
